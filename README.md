# Active ETF Command

台灣主動 ETF 研究工作台，定位為獨立網站：整合每日換股查詢、ETF 評分、持股變化、共識加減碼、台積電 25% 上限壓力測試與報告中心。

## 核心工作流

- 每日變化：依日期、ETF、加碼 / 減碼 / 權重變動查詢主動式 ETF 持倉變化。
- 價值順位：用 AUM、權重與股數推估變動金額，避免只看張數造成高價股與低價股失真。
- 來源揭露：每筆明細保留來源 URL、快照日、比較區間與估算口徑。
- 全站狀態：總控台顯示 ETF 快照新鮮度、失敗檔、盤中攻擊快取狀態。
- 發文素材：單檔 ETF 可複製 Telegram / Threads / 研究稿摘要。

## Run

```bash
npm install
npm run dev -- --port 5176
```

本機網址：

```text
http://127.0.0.1:5176/
```

完整刷新：

```bash
npm run refresh:data
```

單獨更新每日變化資料：

```bash
npm run import:daily
```

## Deploy

本專案可直接部署到 Vercel 或 GitHub Pages。

- Vercel：已提供 `vercel.json`，build command 為 `npm run build`，輸出目錄為 `dist`。
- GitHub Pages：已提供 `.github/workflows/pages.yml`，推到 `main` 後會自動 build 並發布 Pages artifact。

## Features

- 盤後總控：AUM、受益人、台積電曝險、警示數。
- 真實 ETF 資料：從每檔主動式 ETF active 頁匯入 `latestMarket`、完整持股、基金基本資料與 `latestDiff`，完整持股會落地到本機資料檔。
- 資料來源標示：側欄與 ETF 詳情顯示資料日、來源與異動區間。
- 單檔資料可信度：ETF 詳情頁集中顯示 ETF 快照日、完整持股數、持股來源、latestDiff 區間與盤中攻擊快取狀態，判斷刷新優先順序，並可一鍵複製 `npm run refresh:data` 更新指令。
- ETF 資料健康：總控台標示 ETF 快照是否為今日、是否有匯入失敗檔。
- 真實資料品質雷達：集中顯示 ETF 快照、匯入覆蓋、核心欄位完整度與盤中攻擊快取狀態。
- 全站刷新優先級：總控台彙總 ETF 快照與攻擊快取狀態，顯示 ETF 最近生成、攻擊檔更新與下一次 19:00 排程，直接判斷是否建議執行 `npm run refresh:data`，並可預覽、複製 Telegram / Threads 狀態摘要。
- 全 ETF 真實資料稽核：總控台逐檔列出資料日、完整持股筆數、持股來源、latestDiff 區間、攻擊命中與擁擠分數，可切換待處理 / 全部 / 已核對，依投信官方、持股包或缺 latestDiff 篩選，直接開啟來源頁；面板會自動整理快照刷新、高風險複核、持股包複核與補 latestDiff 的優先序，可複製稽核摘要或指定 ETF 刷新命令，並在本機保留固定紀錄加最近 5 筆指定刷新命令紀錄、刷新前後差異狀態、逐檔欄位變化明細，以及 Telegram / Threads 差異摘要預覽與複製；紀錄可單筆刪除、固定保留或清空未固定項目。
- 高擁擠 ETF 警示榜：總控台列出擁擠分數最高且命中攻擊量的 ETF，可切換全部、高擁擠、攻擊命中，點選即可查看詳情、一鍵複製 Telegram 清單，並直接開啟完整擁擠風險矩陣。
- 風險持股 Top 5：總控台列出攻擊命中與擁擠熱區持股最多的 ETF，可切換全部、攻擊、熱區榜單，點代表持股可套用完整持股搜尋，一鍵複製 Telegram 清單，並可開啟完整風險持股排序矩陣。
- 單檔風險持股前 5 名：ETF 詳情頁直接列出完整持股中攻擊命中 / 擁擠熱區權重貢獻最高的持股，附風險權重、風險曝險與最高分，點任一列可鑽取到完整持股明細，並可用 `holding` 參數分享同一筆持股；分享連結會顯示目前聚焦持股提示條。
- 聚焦連結狀態：當研究連結含 `holding` 聚焦持股時，複製按鈕旁會標示「已包含聚焦持股」與代號。
- ETF 矩陣：依台股、海外股票、收益債券分組，並可按指揮分、AUM、折溢價、台積電權重、收益品質與擁擠風險排序。
- 風險持股排序：ETF 矩陣顯示每檔 ETF 的攻擊命中 / 擁擠熱區持股數，並可依風險持股數排序。
- 收益品質：債券型 ETF 以殖利率、配息頻率、費率、折溢價、AUM 與受益人規模獨立評分。
- 收益風險提示：債券型 ETF 顯示殖利率缺值或偏低、折溢價偏離、費率偏高、規模與受益人較小等旗標。
- 共識資金流：統計多檔 ETF 同步加減碼的股票。
- Flow Command：估算主動圈加碼/減碼金額、產業流向、ETF 領頭與完整異動明細。
- 攻擊量疊圖：在資金流頁標出同時被盤中攻擊量命中的流向個股。
- 重疊持股熱區：以完整持股統計多檔 ETF 共同持有股票、合計權重、曝險、latestDiff 與攻擊量命中。
- 盤中攻擊：把台股盤中攻擊量訊號與 ETF 完整持股交集。
- 攻擊空狀態：沒有攻擊事件或 ETF 交集時，頁面會顯示原因與更新路徑。
- ETF 受影響排行：把攻擊股權重、曝險與加碼關係轉成 ETF 層級分數。
- 攻擊排行跳轉：點選受影響 ETF 可直接進入 ETF 矩陣詳情。
- ETF 詳情攻擊曝險：每檔 ETF 詳情可直接查看命中的盤中攻擊股。
- 完整持股明細：單檔 ETF 詳情可搜尋完整持股，依權重、風險貢獻、股數或代號排序，篩選攻擊命中 / 擁擠熱區，即時計算目前篩選權重、曝險與風險權重，可一鍵回到全部、顯示全部 / 收合，並複製含風險分數與風險曝險的目前篩選結果 CSV。
- ETF 擁擠交易風險：把重疊持股熱區反推到每檔 ETF，詳情卡顯示熱區分數、曝險與攻擊命中。
- 擁擠熱區拆解：單檔 ETF 詳情列出前三大共同持股熱區、貢獻分、權重、曝險、共同持有檔數、同持 ETF 權重與攻擊命中。
- 擁擠風險摘要複製：一鍵輸出單檔 ETF 的擁擠等級、熱區曝險、攻擊命中與主要熱區。
- 攻擊敏感排序：ETF 矩陣可依盤中攻擊受影響分數排序。
- 攻擊資料降權：非今日攻擊快取會以歷史權重調整矩陣排序、表格分數與對比結論。
- 可分享研究視圖：頁籤、搜尋、ETF 類型、選中 ETF、排序會同步到網址。
- 一鍵複製連結：把目前研究狀態複製成可分享網址。
- 一鍵貼文摘要：把 ETF 評分、持股、攻擊曝險與研究連結整理成可貼 Telegram / Threads 的短文。
- 摘要資料時戳：貼文與對比摘要會標示盤中攻擊資料是否為今日或過期快取。
- 摘要格式切換：同一檔 ETF 可輸出 Telegram 交易卡、Threads 短文或長版研究稿。
- 攻擊更新入口：盤中攻擊頁顯示目前來源檔、修改時間與可複製的完整匯入指令。
- ETF 異動日曆：報告中心顯示下一次 19:00 刷新、ETF 快照、latestDiff 區間與盤中攻擊快取。
- ETF 異動日曆摘要：報告中心可用 Telegram / Threads 兩種格式，切換最新區間 / 全部區間，預覽並一鍵複製下一次 19:00 排程、ETF 快照、latestDiff 區間與盤中攻擊快取摘要。
- 投信風格分群：報告中心依投信彙總 AUM、經理人、台股/海外/債券配置、台積電平均權重與異動活躍度，並可依 AUM、異動、台積電集中與收益占比排序。
- ETF 雙檔對比：在詳情卡比較指揮分、AUM、台積電權重、盤中攻擊分與折溢價差值。
- 對比摘要複製：把雙檔 ETF 差異整理成可貼的研究摘要。
- 對比勝出標籤：直接標出指揮分、規模、集中風險、攻擊敏感與折溢價優勢。
- 對比結論句：把雙檔優勢轉成一行客觀研究判斷，並同步放入複製摘要。
- 資料新鮮度：標示盤中攻擊資料是否為今日快取。
- 25% 監管雷達：台積電權重與價格壓力測試。
- 報告中心：早報、資金流摘要、週報輸出框架。

## Data

`src/data/etfUniverse.js` 由真實資料匯入器產生，預設抓取 ETF資訊網每檔主動式 ETF 的 active 頁：

```bash
npm run import:etfs
```

匯入欄位包含：

- `latestMarket`：資料日、市價、NAV、折溢價、AUM、受益人數。
- `info`：基金全名、類型、發行投信、經理人、成立日、費率、配息與官方頁。
- `holdings`：完整持股，前五大持股會進入工作台。
- `latestDiff`：最近一次持股異動，用於加碼、減碼、共識資金流。

可用環境變數：

```bash
ACTIVE_ETF_SCOPE=all          # all / stock / tw-equity
ACTIVE_ETF_CODES=00981A,00991A
```

`npm run dev` 與 `npm run build` 會自動嘗試刷新 ETF 真實快照，並從本機短線監控快取更新盤中攻擊資料。也可以手動執行：

```bash
npm run import:intraday
```

同時刷新 ETF 與盤中攻擊資料：

```bash
npm run refresh:data
```
